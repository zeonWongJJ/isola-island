# ISOLA · 潮汐之岛

一座可以 360° 自由查看的 Three.js 微缩海岛。包含灯塔、瀑布、农场、市集、帆船港口、蓝色洞穴和远海遗迹，支持白昼、日落、星夜切换，以及随视角和波纹变化的海面倒影。

西南海面新增「黑潮号」三桅海盗船：黑帆与骷髅纹章、14 个舷侧炮门、绳梯与瞭望台、船尾窗廊、舵轮、锚、绞盘、航海图和宝箱。船身随海浪轻轻摇摆，船灯与舱窗参与真实海面倒影；通过第 11 个目的地可单独环绕查看。

西北海面新增「海盗秘湾岛」：马蹄形浅湾、石砌旧堡垒、修船棚与吊机、木船骨架、酒馆和渔民小屋。第 12 个目的地可独立环绕；码头、沿湾步道、房屋门口和堡垒楼梯相连，局部暖灯与倒影随时段变化。主岛沙滩增加湿沙和渐深的沙质浅滩，近岸减弱反射，水色逐渐过渡到外海。

[在线访问](https://zeonwongjj.github.io/isola-island/)

## 操作

- 拖动旋转，滚轮缩放；手机支持双指缩放与平移。
- 点击目的地或地标，镜头自动靠近景点。
- 点击「沉浸查看」收起界面，按 Esc 退出。
- 手机端通过底部「探索岛屿」打开目的地列表。
- 支持自动环绕、环岛漫游和原画对照。

## 本地开发

使用 Node.js 20 或更新版本。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

测试覆盖楼梯遮挡与切口封边、步道支撑、市集摊位退界和住宅入口、路肩与草根贴地、建筑基座、桥头、码头、洞穴、岛礁、海盗船与海岸和礁石的间距、船灯随动、新岛道路与建筑支撑及通行空间、镜头取景、天空可见性，以及倒影相机、海平面裁剪和渲染状态恢复。

## 发布到 GitHub Pages

```sh
npm run build:pages
git add docs/index.html
git commit -m "Update island website"
git push
```

GitHub 仓库的 Settings → Pages 使用 **Deploy from a branch**，选择 **main** 分支的 **/docs** 文件夹。

`docs/index.html` 包含脚本、样式和原画图片，不依赖站点根路径，可以通过仓库子路径访问，也可以下载后直接打开。保留 `docs/.nojekyll`。

## 项目结构

- `src/`：场景、模型、地形、水面、天空、灯光与交互。
- `public/reference.png`：原始海岛概念图。
- `tests/`：结构与取景检查。
- `build-portable.mjs`：生成单文件网页。
- `docs/`：GitHub Pages 发布文件。
